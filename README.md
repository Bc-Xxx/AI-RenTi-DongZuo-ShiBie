# AI人体动作识别

基于 YOLO11 的工厂围栏安防检测系统：**攀爬翻越围栏检测**、**抛掷物品检测**、**抽烟违规检测** 三大模块 + 本地 Web 管理平台（多摄像头配置与切换 / 实时画面 / 模块开关 / 参数在线调节 / 告警截图）。

设计目标：部署在边缘计算盒（NVIDIA Jetson Orin NX）上，接入工厂 RTSP 监控相机，7×24 小时实时检测与告警。

## 功能模块

| 模块 | 判定逻辑 | 告警级别 |
|---|---|---|
| 攀爬翻越 | 黄框布防区 + 脚底轨迹穿过围栏顶线（几何判定）+ 时间窗口内攀爬姿态证据（手腕持续高于肩） | 预警 / 告警 |
| 抛掷物品 | 仅快速挥臂 = 预警；挥臂动作 + 物体帧差飞越墙头线 = 告警（挥臂是必要条件，过栏仅作升级佐证不单独告警）；手持物关联（背包/手提包/箱类）作辅助标注 | 预警 / 告警 |
| 抽烟违规 | 烟头/吸烟目标检测 + 连续 N 帧关联到同一人 | 告警 |

多证据投票设计：单一证据不告警，多项证据对上才升级为正式告警，压误报。

## 文件说明

| 文件 | 说明 |
|---|---|
| `app.py` | 入口：拉起检测引擎与 Web 服务，`python app.py` 启动 |
| `config.py` | **全部配置集中地**：运行参数默认值、文件路径、各模块算法常量（运行参数存 `web_config.json`，网页调节自动保存） |
| `engine.py` | 检测引擎主循环（编排：取流热切换 → 证据计算 → 各模块规则 → 绘制 → 告警） |
| `capture.py` | 取流（后台线程只保留最新帧、断流重连、视频源限速回放） |
| `zones.py` | 黄框布防区标定存储（按相机）+ 几何判定（跨线等） |
| `alerts.py` | 告警记录、证据截图、推流共享帧 |
| `evidence.py` | 模型推理层：YOLO 人/物品/姿态/抽烟模型的加载与证据计算（换模型只改这里） |
| `viz.py` | 画面叠加绘制（中文角标、标定框、告警标签、过带轨迹） |
| `web.py` + `index.html` | FastAPI 接口与 Web 界面（实时画面、相机管理、参数滑条、告警列表、画布防区） |
| `modules/` | 检测模块规则（climb/throw/smoke，纯判定可单测；**新模型接入步骤见其 `__init__.py`**） |
| `climb_config.json` | 黄框布防区标定存储（按相机，网页上鼠标绘制） |
| `prepare_repo.py` | 打包上传 GitHub 的辅助脚本（配合 `一键上传GitHub.bat`，自动清洗相机密码） |

## 快速开始

```bash
# 1. 安装依赖（Python 3.10+）
pip install ultralytics fastapi uvicorn

# 2. 启动后浏览器打开 http://localhost:8000，右上角「＋」添加相机取流地址
#    (也可直接编辑 web_config.json 的 cameras 列表)
# 3. 下载预训练权重放到本目录（首次运行也会自动下载）
#    https://github.com/ultralytics/assets/releases  下载 yolo11s.pt 和 yolo11s-pose.pt
#    抽烟模块需自训权重 smoke_best.pt（缺失时该模块自动跳过）

# 4. 启动
python app.py
```

## 使用流程

1. **多摄像头**：顶部相机标签点击切换画面；「＋」进入摄像头管理，可新增/改名/删除/测试取流地址（支持 RTSP、`0`=USB 摄像头、本地视频文件路径）。每个相机独立记住自己的检测参数和攀爬黄框标定，切换即时生效无需重启；告警文本与截图文件名自动带相机标识
2. 顶栏页签开关三个检测模块，齿轮图标进入各模块参数设置（阈值类参数跟随当前相机保存）
3. 攀爬设置 → “绘制/重画黄框” → 在画面上点击圈住围栏（**前两个点决定墙头触发线**），右键撤销，双击完成
4. 滑条调参即时生效并持久化；告警自动截图存 `alerts/` 目录
5. 首次部署需现场标定：置信度阈值、人框最小高度、手腕速度阈值等（说明见 `web_config.json` 的 `_说明` 字段；换机位后参数与黄框需按相机重标）

## 部署说明

- 开发调试：Windows + CPU 可运行；正式部署：Jetson Orin NX（建议导出 TensorRT engine 加速，`yolo export model=xx.pt format=engine`）
- 相机建议：RTSP over TCP（代码已内置），围栏点位建议主码流 1080p
- 夜间红外画面姿态证据可靠性下降，可将 `require_posture` 设为 0 切换为纯几何判定兜底

## 注意事项

- 相机账号密码等敏感信息请只写在本地 `web_config.json`，**不要提交到仓库**（本项目模板中已替换为占位符）
- ultralytics 为 AGPL-3.0 协议，本地部署使用无开源义务，封装为对外商业 SaaS 需注意授权
